2. Tipos de variables

¿Qué es?

Una variable es un espacio identificado por un nombre donde se guarda un dato que el programa puede utilizar. En JavaScript se declaran principalmente con var, let y const.

¿Para qué sirve?

Declarar variables permite conservar datos, reutilizarlos, modificarlos cuando corresponda y hacer que los programas sean más claros.

Elementos y tipos principales

Elemento o tipoDefinición y uso
varTiene alcance de función o global y permite redeclarar y reasignar. En código moderno suele evitarse porque su alcance puede causar confusiones.
letTiene alcance de bloque. Permite cambiar el valor, pero no declarar otra variable con el mismo nombre en el mismo bloque.
constTiene alcance de bloque y no permite reasignar la variable. Debe recibir un valor al declararse; si guarda un objeto, sus propiedades todavía pueden cambiar.

Ejemplo de código

Este ejemplo muestra cómo se utiliza el tema en JavaScript. Puedes copiarlo y probarlo en un archivo HTML.

let edad = 16;
edad = 17; // se puede reasignar

const escuela = "CBTIS";
// escuela = "Otra"; // produciría un error

var ciudad = "Actopan";
document.write(edad + " - " + escuela + " - " + ciudad);
