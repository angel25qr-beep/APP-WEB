6. Estructura switch

¿Qué es?

switch es una estructura de control que compara una expresión con diferentes casos (case). Cuando encuentra una coincidencia, ejecuta las instrucciones de ese caso.

¿Para qué sirve?

Se utiliza cuando hay varias opciones posibles para una misma variable o expresión, por ejemplo, un menú, los días de la semana o una selección de operaciones.

Elementos y tipos principales

Elemento o tipoDefinición y uso
switchEvalúa la expresión una sola vez y busca un caso que coincida.
caseRepresenta una opción posible.
breakTermina el switch para evitar que continúe ejecutando los siguientes casos.
defaultSe ejecuta cuando ningún case coincide; es opcional.

Ejemplo de código

Este ejemplo muestra cómo se utiliza el tema en JavaScript. Puedes copiarlo y probarlo en un archivo HTML.

let dia = 3;

switch (dia) {
    case 1:
        document.write("Lunes");
        break;
    case 2:
        document.write("Martes");
        break;
    case 3:
        document.write("Miércoles");
        break;
    default:
        document.write("Día no válido");
}
